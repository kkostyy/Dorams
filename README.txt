DORAMA CUTTER — как получить APK (без Android Studio)

1. Зарегистрируйся на github.com (бесплатно) и нажми New repository (имя любое, например dorama).
2. Распакуй этот архив. На странице репозитория нажми "uploading an existing file"
   и перетащи ВСЁ содержимое папки DoramaCutter (папки app и .github тоже).
   Нажми Commit changes.
   Если папка .github не загрузилась (скрытая): нажми Add file -> Create new file,
   в имени напиши  .github/workflows/build.yml  и вставь текст из файла build.yml.txt.
3. Открой вкладку Actions. Сборка стартует сама (3–6 минут). Если нет — выбери "Build APK" -> Run workflow.
4. Когда появится зелёная галочка, открой запуск и внизу в разделе Artifacts скачай DoramaCutter-apk (zip).
   Внутри app-debug.apk. Перекинь на телефон и установи (разреши установку из неизвестных источников).
5. Если сборка красная: открой запуск, скопируй текст ошибки из шага Build и пришли в чат — поправлю.

Как пользоваться: выбери видео -> введи название, @telegram, хештеги -> Начать нарезку.
Готовые части появятся в галерее (Movies/DoramaCutter), описания — в Download/DoramaCutter.
Во время нарезки не сворачивай приложение, держи телефон на зарядке.

ИИ-АНАЛИЗ (необязательно)
1. Получи бесплатный ключ: aistudio.google.com/apikey (нужен аккаунт Google).
2. Вставь ключ в приложение, выбери видео и нажми «ИИ: найти места для разреза».
   Приложение достанет звук, загрузит его в Google (150–350 МБ, лучше по Wi-Fi) и вернёт
   клиффхэнгеры, заголовки, тексты финального экрана и хештеги.
3. Проверь план на экране и жми «Начать нарезку».
Если ошибка про модель (404) — поменяй название в поле «Модель Gemini» на актуальное из AI Studio.
